# Steam Float Scanner releases

The current private Windows release is
[v0.2.138](https://github.com/Rigby453/steam-float-scanner-releases/releases/tag/v0.2.138).
All seven assets were downloaded with owner authentication and hash-matched:
installer, blockmap, signed manifest, latest.yml, build verification, exact source
archive and source provenance. The installer SHA-256 is
`49798f5038ae6ad1de2046845429b5ec60110be9c1702b526d83bb8d0e43dbff`.

This repository remains private at the owner's request. Authorized GitHub access
or the owner's verified local EXE is required for manual installation. The current
application updater performs unauthenticated requests and cannot fetch private
release assets. A protected server download with SFS authorization is not yet
implemented or deployed; no shared GitHub credential is embedded in the app.
Historical public updater checks describe access before the repository became
private, not current availability.
