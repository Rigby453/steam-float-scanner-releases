# Steam Float Scanner releases

Official Windows installers, signed update manifests and source archives for
Steam Float Scanner. The current published version is
[v0.2.137](https://github.com/Rigby453/steam-float-scanner-releases/releases/tag/v0.2.137).
Older releases remain available in the [release history](https://github.com/Rigby453/steam-float-scanner-releases/releases).

The [source repository](https://github.com/parserst/steam-float-scanner) holds
application code, rules, release notes and verification records (access may be
required). The [v0.2.137 source tag](https://github.com/parserst/steam-float-scanner/tree/v0.2.137)
identifies the exact code for this installer; later documentation can advance on
main. Read the [changes](https://github.com/parserst/steam-float-scanner/blob/main/docs/releases/0.2.137.md),
[verification](https://github.com/parserst/steam-float-scanner/blob/main/docs/RELEASE_0_2_137.md)
and [Steam Guard guide](https://github.com/parserst/steam-float-scanner/blob/main/docs/steam-guard-import.md).
Each published version's installer, updater files and source archive are attached
to its release page. Use the exact versioned assets and recorded hashes when
comparing an installed build or preparing an update.

This repository's README is a navigation page. Release assets and historical
tags are preserved as published; local profiles, logs and experimental builds
are held outside GitHub.
